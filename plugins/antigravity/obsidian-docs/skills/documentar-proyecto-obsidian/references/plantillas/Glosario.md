## A

### API
**Qué es:** Una "ventanilla" por la que un programa le pide datos o acciones a otro.
**Analogía:** Como el mesero de un restaurante: tú (la app) pides, él lleva el pedido a la cocina (el servidor) y te trae el plato (los datos).
**En este proyecto:** La app móvil usa la API para crear pedidos (`POST /pedidos`).
